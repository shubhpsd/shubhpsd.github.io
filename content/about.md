## Featured Projects

### Yoga Pose Classifier & Feedback System

Built and deployed an end-to-end computer vision pipeline that classifies **107
distinct yoga poses** from live video stream, achieving approximately **75%
accuracy** on a 5.6k image test dataset.

**[GitHub](https://github.com/shubhpsd/yoga-pose-detection) |
[Live Demo](https://detectpose.streamlit.app/)**

### Dual-Model Movie Recommendation System

Architected a hybrid recommendation engine combining content-based filtering and
popularity-based model, utilizing TF-IDF vectorization to transform movie
metadata into a **5,000-dimensional feature space**.

**[GitHub](https://github.com/shubhpsd/movie-recosystem)**

### GitHubFetch CLI Tool

Developed and published on **PyPI** - a Python CLI tool for viewing stylized
GitHub profiles directly in the terminal, engineered to query GitHub GraphQL and
Rest API.

transaction management, featuring dynamic visualizations across 6+ custom

**[Live Demo](https://track-expense.streamlit.app/)**
